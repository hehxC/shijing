# 石境 MVP 核心流程

## 1. 产品承诺

石境帮助石材门店销售和小型庭院设计师，在五分钟内根据可选的庭院空间图、可选的石材方案与必选的庭院风格生成一份可继续修改的庭院效果方案，并基于材料库中的真实数据提供材料与预算参考。

MVP 的成功结果不是完成若干轮聊天，而是用户成功生成至少一张效果图，能够继续修改或咨询，并可以从历史设计中恢复该方案。

## 2. 目标用户

第一阶段优先服务：

- 需要快速制作售前效果方案的石材门店销售；
- 需要与客户快速确认风格和材料方向的小型庭院设计师。

庭院改造业主可以使用相同流程，但不是第一阶段进行业务验证的主要对象。

## 3. 唯一主流程

```text
访问产品
  → 注册或登录
  → 新建设计
  → 上传庭院空间图（可选，最多一张）
  → 上传石材参考图（可选，最多二十张）
  → 选择庭院风格（生成效果图时必选）
  → 明确点击“效果图”
  → 等待并查看生成结果
  → 输入文字继续修改（可选）
  → 查询材料或预算（可选）
  → 自动保存，并可从历史设计恢复
```

产品的唯一主工作台是 `/`。旧的 `/static/index.html`、`/static/step2.html` 和 `/static/step3.html` 多页面流程统一重定向到 `/`，不再作为独立产品入口。

移动端仍遵循 ADR 0005，在同一网址内使用“设计素材、庭院风格、生成与聊天”三个页面状态；桌面端使用同一工作台的并列布局。

## 4. 必选与可选条件

### 必选

- 用户必须注册或登录后才能上传素材、聊天和生成效果图；
- 生成效果图时必须选择一个有效的庭院风格；
- 效果图生成必须由用户明确点击“效果图”触发。

仅选择风格或发送普通聊天消息不得隐式触发效果图生成。

### 可选

- 庭院空间图可选；缺少时系统根据庭院风格自行设计布局；
- 石材方案可选；缺少时系统根据庭院风格设计通用方案；
- 石材名称和石材用途可选；缺少时由系统合理安排；
- 文字追改、识图、材料咨询和预算参考均为生成后的可选操作。

## 5. 页面状态

| 状态 | 主要操作 | 成功去向 | 失败行为 |
| --- | --- | --- | --- |
| 未登录 | 注册、登录 | 空白设计 | 保持登录界面并显示原因 |
| 空白设计 | 添加可选素材、选择风格 | 设计准备完成 | 保留已成功保存的输入 |
| 设计准备完成 | 明确点击“效果图” | 正在生成 | 缺少风格时定位到风格选择 |
| 正在生成 | 等待、停止 | 已生成或生成失败 | 禁止重复提交 |
| 已生成 | 查看、追改、识图、报价 | 更新后的设计 | 保留当前效果图和设计上下文 |
| 生成失败 | 查看错误、重试原请求 | 正在生成 | 不清空素材、风格和用户要求 |
| 历史设计 | 恢复、重命名、永久删除 | 已恢复设计 | 无权限时拒绝访问 |

## 6. 当前效果图与重新生成

庭院空间图、庭院风格和石材方案均未变化时，用户提出“增加瓦片围边”“调整灯光”等要求，系统基于当前效果图继续编辑。

以下任一内容变化后，旧效果图仍可查看，但不再是下一次生成的编辑基础：

- 更换庭院空间图；
- 增加、删除或替换石材参考图；
- 修改石材名称或用途；
- 更换庭院风格。

下一次明确点击“效果图”时，系统使用最新设计素材重新生成完整方案。

## 7. 材料与预算边界

MVP 只承诺：

- 查询材料库已经收录的材料；
- 返回数据库中的真实规格、颜色、单位和价格；
- 在面积与单价均有依据时提供参考估算；
- 材料或价格未收录时明确说明无法可靠报价。

MVP 不承诺：

- 自动获取实时市场价格；
- 用常识或模型记忆补充市场价；
- 输出正式商业报价；
- 精确计算人工费、运输费和施工损耗；
- 输出专业施工图、结构安全结论或当地规范审批意见。

材料库缺少记录时，统一遵循：

> 当前材料库未收录该材料或价格，无法提供可靠报价。

## 8. 第一阶段非目标

- 新增更多 Agent；
- 新增模型供应商；
- 为展示技术扩大 RAG 或 MCP 范围；
- 自动施工图和结构安全判断；
- 支付、套餐和额度购买；
- 社区、作品分享和多角色协作；
- 自动抓取市场价格；
- 复杂运营后台。

新需求只有在能够直接提高“五分钟内完成初步方案”的成功率时，才进入第一阶段范围。

## 9. 验收案例

### 最短路径

登录 → 选择风格 → 点击“效果图”。没有上传图片也应成功生成。

### 标准路径

登录 → 上传空间图 → 上传石材图 → 选择风格 → 点击“效果图”。所有素材应被正确使用并保存。

### 普通聊天不隐式生成

登录 → 选择风格 → 发送普通问题。系统只回答问题，不得生成效果图。

### 连续修改

生成效果图 → 输入“增加瓦片围边”。设计上下文未变化时应编辑当前效果图。

### 素材变化

生成效果图 → 更换风格 → 再次点击“效果图”。系统应重新生成完整方案。

### 价格不存在

询问材料库未收录材料的价格。系统应说明未收录，不得编造价格。

### 生成失败

图像模型请求失败后，庭院空间图、石材方案、庭院风格和用户要求均应保留，并允许重试原请求。

## 10. 完成标准

- 本文档与 `CONTEXT.md` 和现有 ADR 不冲突；
- 产品只有一个主工作台和一条主流程；
- 生成效果图必须由明确操作触发；
- 必选、可选、失败和恢复行为均有定义；
- 材料与价格能力边界明确；
- 上述七个验收案例均可执行；
- 新用户能够在五分钟内完成第一份效果方案。
